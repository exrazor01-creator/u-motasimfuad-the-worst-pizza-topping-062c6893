A one-line entry for the "The Worst Pizza Topping" bounty: pitch the worst pizza topping in a single funny line. The line sells gummy bears melted into the cheese as if it were a premium feature — every slice stretches, squeaks, and sticks to your teeth for a week. The program validates the line (at most 200 characters, ASCII, single line) and writes it to `entry.txt`.

## Run it

```sh
python3 main.py
```
